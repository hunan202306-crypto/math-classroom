初中数学 · 函数
一次函数的基本认识

一次函数通常写成 y = kx + b（k ≠ 0）。其中 x 是自变量，y 随 x 的变化而变化。

y = 2x + 1

例题：已知 y = 2x + 1，当 x = 3 时，求 y。

  1. 写出函数关系式：y = 2x + 1。
  2. 把 x = 3 代入：y = 2 × 3 + 1。
  3. 计算得到：y = 7。
学习提醒：代入数值时，注意乘法与加减法的运算顺序。
